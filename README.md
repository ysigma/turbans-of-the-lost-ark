# Turbans of the Lost Ark: The Search for the Diamond Rumal

A procedural 3D jungle explorer in the browser. Play as Jasmeet Singh, Babbu or Bibi, collect turbans to shouts of "Waheguru!", dodge Bikraam Singh's chappals and Papaji's homework, and find the Diamond Rumal on the Lost Ark.

Play: https://ysigma.github.io/turbans-of-the-lost-ark/

Works on desktop (keyboard + mouse) and phones (touch controls). Needs an internet connection for the 3D engine and fonts.
